# PresuBot — Demostración

SaaS provisional para profesionales de reformas, pintura, fontanería, electricidad e instalaciones.

## Qué es esta versión

Demostración local (HTML + JavaScript + localStorage). No envía datos a ningún servidor. No es un producto comercial operativo.

## Cómo probar

1. Abre `index.html` en un navegador.
2. Usa el formulario de solicitud.
3. Guarda en el panel local y cambia estados.

## Despliegue público (GitHub Pages)

1. Crea un repositorio público llamado `presubot-demo` (o similar).
2. Sube los archivos de esta carpeta.
3. Ve a Settings → Pages → Deploy from branch → main → / (root).
4. La URL será `https://TUUSUARIO.github.io/presubot-demo/`.

No se ha desplegado automáticamente porque requiere acción del propietario de la cuenta.

## Limitaciones

- Sin backend, base de datos, autenticación ni pagos.
- IA simulada de forma determinista (no llamada a modelo externo).
- Panel solo local.
- Borradores legales con marcadores.
